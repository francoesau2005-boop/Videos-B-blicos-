# Rey Pollo

Juego original de restaurante de pollo frito (estilo "idle arcade"): fríe pollo, llévalo a la vitrina,
atiende en la caja, cobra, limpia mesas y usa el dinero para desbloquear mesas, freidoras, refrescos
y ayudantes (cajero, ayudante de cocina y limpiador). Tiene mejoras de velocidad, capacidad,
freidoras rápidas y mejor receta. El progreso se guarda en el navegador.

- **Jugar en PC:** abre `ReyPollo.html` con Chrome, Edge o Firefox (necesita internet la primera vez para cargar three.js).
- **Controles:** WASD o flechas; también puedes hacer clic y arrastrar.
- `juego.html` es la misma página sin el esqueleto HTML (la versión que se publica como Artifact).
